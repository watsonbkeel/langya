## M0 — 骨架与连通

**目标**：跑通「浏览器 → 服务器 → 浏览器」的完整链路，后面所有功能都长在这条链路上。

### 任务清单

- [ ] `server/` Node.js + TypeScript 工程初始化（`tsc --noEmit` 通过）
- [ ] `client/` Cocos Creator 3.8 工程初始化，能无头构建出 `build/web-mobile/`
- [ ] `shared/protocol.ts` 定义基础消息类型（`join` / `snapshot` / `ping`）
- [ ] `shared/config/*.json` 加载器 + 启动校验（四波总和 == 200，否则拒绝启动）
- [ ] HTTP 静态服务监听 `0.0.0.0:8080`，托管客户端构建产物
- [ ] WebSocket 服务监听 `0.0.0.0:8081`（或同端口 `/ws` 升级）
- [ ] 客户端 WS 地址从当前域名推导，**不硬编码 IP**
- [ ] 空白场景 + 一行文字「已连接，延迟 xx ms」
- [ ] PM2 常驻，`pm2 startup` 开机自启
- [ ] `tools/check-ws.js` 连通性自测脚本可用

### 完成判据

```bash
curl -I http://127.0.0.1:8080          # 200
curl -I http://100.126.150.80:8080     # 200（Tailscale 内网可达）
node tools/check-ws.js ws://127.0.0.1:8081/ws   # 握手成功 + 收到心跳
```

浏览器打开 `http://100.126.150.80:8080` 看到「已连接，延迟 xx ms」。

## M1 — 战斗核心

### 任务清单

- [ ] 服务器 20Hz 主循环（`setInterval` + 时间补偿，不用裸 `setTimeout`）
- [ ] `combat/` 纯函数：`calculateDamage(weapon, distance, hitPart)` + 单元测试
- [ ] 玩家输入上报（视角、开火、换弹）
- [ ] 射线命中判定**在服务端**，客户端只播特效
- [ ] 敌人实体生成 + 血量 + 死亡移除
- [ ] 中正式步枪完整循环：开火 → 后坐 → 拉栓 → 换弹
- [ ] 客户端第一人称视角 + 准心 + 弹药 HUD
- [ ] 命中反馈：准心命中标记 + 伤害数字 + 击杀提示
- [ ] 玩家血量与受击反馈（屏幕边缘红晕）

### 完成判据

放 1 个静止敌人，玩家能瞄准、开火、看到命中反馈、把它打死。开一枪到反馈的延迟主观上「跟手」。

## M2 — AI 队友

**目标**：4 名 AI 队友分守三条路线，**能帮忙但不能抢戏**。

### 任务清单

- [ ] 房间席位系统：5 席，真人优先，空席补 AI（PRD 2.5）
- [ ] AI 队友按 `allies.json` 的 `deployment.defaultAssignment` 分配路线（A:1 / B:2 / C:1）
- [ ] 队友不跟随玩家、不用重机枪、不捡空投、不参评 MVP
- [ ] 玩家驻守某路线超过 8 秒 → 该路线队友自动调往其他路线
- [ ] 喊话系统：路线告警 / 低血 / 稳住 / 阵亡，含 8 秒冷却
- [ ] HUD 三路线威胁指示器（配合喊话闪烁）
- [ ] 日军 AI 状态机：移动 → 寻找掩体 → 开火 → 死亡
- [ ] 路径点导航 + 随机偏移（避免排队行军）
- [ ] 开火预警 0.35 秒（枪口焰先于伤害）
- [ ] AI 分 4 组轮转决策（每实体 5Hz）
- [ ] `tools/simulate-match.js` 批量模拟脚本

### 完成判据

**必须实测**（这是本里程碑的硬指标）：

```bash
node tools/simulate-match.js --runs 10 --output stats.json
```

- 4 名队友合计歼敌占比 ≤ 50%（目标 40%）
- 队友平均存活 ≥ 180 秒
- 单局服务端 CPU < 20%（单核，44 个 AI 实体）

超标时按 `allies.json` 的 `calibration.tuningOrder` 顺序下调：命中率 → 射速 → 反应延迟 → 血包数。

### 完成记录

> **必须填写实测数据**：10 局的队友歼敌占比、玩家歼敌占比、队友平均存活、CPU 占用；调整了哪些参数、调整前后对比

## M3 — 完整单局 ⭐ 交付节点

**目标**：单人能完整打完 5 分钟并看到战报。**这是最重要的节点，完成后必须停下来交 watson 试玩。**

### 任务清单

- [ ] 四波调度器：30 / 50 / 60 / 60，滚动小队投放
- [ ] 同屏上限 40，达上限暂缓投放（不丢弃，排队）
- [ ] 波次间隔提示 + 剩余敌人计数 HUD
- [ ] 玩家 2 个血包 + 山上随机空投血包
- [ ] AI 队友 1 个血包、低于 30% 自动使用、不捡空投
- [ ] 2 处定点重机枪：进入/退出、俯仰角限制、过热冷却
- [ ] 武器切换：步枪 / 轻机枪 / 手榴弹
- [ ] 5 分钟倒计时 + 胜负判定（存活即胜利）
- [ ] MVP 计分：仅真人参评
- [ ] 战报页：歼敌数、命中率、存活时长、各波表现
- [ ] SQLite 落库战报

### 完成判据

从进入到战报全程无卡死、无数值异常。**200 名敌人全部投放完毕**（波次调度不能漏人）。

### ⚠️ 交付要求

完成后**停止开发**，输出：
1. 可访问地址
2. 一段试玩说明（操作方式、预期难度）
3. 已知问题清单

等 watson 试玩反馈后再进 M4。
