## ⚠️ 双机协作说明

本项目由 **Debian（服务端）** 和 **Mac（客户端）** 两台机器并行开发。

任务清单里的标记：

| 标记 | 含义 |
|---|---|
| 🖥️ | Debian 负责 |
| 💻 | Mac 负责 |
| 🤝 | 需要双方配合，先约定接口再各自实现 |

**只勾选自己完成的项，不要替对方勾。** 「完成记录」栏双方各写各的，用小标题区分。

一个里程碑要**双方都做完**才算完成，状态才能改成 ✅。

## M0 — 骨架与连通

**目标**：跑通「浏览器 → 服务器 → 浏览器」的完整链路，后面所有功能都长在这条链路上。

### 任务清单

> **顺序：Debian 先做完服务端并推送，Mac 再接客户端**（Mac 需要有服务器才能连）。
> `shared/protocol.ts` 由 Debian 先定义并推送，Mac 直接 import，不要自己写一份。

**🤝 先约定（Debian 起草，推送后 Mac 拉取）**
- [x] `shared/protocol.ts` 定义基础消息类型（`join` / `snapshot` / `ping` / `pong`）

**🖥️ Debian**
- [x] `server/` Node.js + TypeScript 工程初始化（`tsc --noEmit` 通过）
- [x] `shared/config/*.json` 加载器 + 启动校验（复用 `tools/verify-config.js` 的规则，不通过拒绝启动）
- [x] HTTP 静态服务监听 `0.0.0.0`，托管客户端构建产物
- [x] WebSocket 服务监听 `0.0.0.0`（或同端口 `/ws` 升级）
- [x] 心跳与延迟计算
- [x] PM2 常驻，`pm2 startup` 开机自启
- [x] 验证 `tools/check-ws.js` 可连通

**💻 Mac**

- [ ] 空场景（只有 Canvas + Camera + GameRoot）

## M2 — AI 队友

**目标**：4 名 AI 队友分守三条路线，**能帮忙但不能抢戏**。

### 任务清单

> **Debian 先做完 AI 逻辑并推送，Mac 再做表现层。** AI 全部跑在服务端。

**🖥️ Debian（本阶段主力）**
- [ ] 房间席位系统：5 席，真人优先，空席补 AI（PRD 2.5）
- [ ] AI 队友按 `allies.json` 的 `deployment.defaultAssignment` 分配路线（A:1 / B:2 / C:1）
- [ ] 队友不跟随玩家、不用重机枪、不捡空投、不参评 MVP
- [ ] 玩家驻守某路线超过 8 秒 → 该路线队友自动调往其他路线
- [ ] 喊话触发逻辑 + 8 秒冷却（服务端决定何时喊，客户端只负责显示）
- [ ] 日军 AI 状态机：移动 → 寻找掩体 → 开火 → 死亡
- [ ] 路径点导航 + 随机偏移（避免排队行军）
- [ ] 开火预警 0.35 秒（枪口焰先于伤害）
- [ ] AI 分 4 组轮转决策（每实体 5Hz）
- [ ] `tools/simulate-match.js` 实现（**复用 server 战斗逻辑，禁止另写简化模型**）
- [ ] 跑 10 局校准，达标后把数据写进完成记录

**💻 Mac**
- [ ] 队友状态面板（姓名、血量、所在路线、存活状态）
- [ ] 喊话 UI：气泡/字幕 + 音效占位
- [ ] HUD 三路线威胁指示器（配合喊话闪烁）
- [ ] 敌人 AI 状态的视觉表现（移动、掩体、开火预警的枪口焰）
- [ ] 队友与敌人仍用色块区分（美术在 M4）

### 完成判据

**必须实测**（这是本里程碑的硬指标）：

```bash
node tools/simulate-match.js --runs 10 --output stats.json
```

- 4 名队友合计歼敌占比 ≤ 50%（目标 40%）
- 队友平均存活 ≥ 180 秒
- 单局服务端 CPU < 20%（单核，44 个 AI 实体）

超标时按 `allies.json` 的 `calibration.tuningOrder` 顺序下调：命中率 → 射速 → 反应延迟 → 血包数。

### 完成记录

#### 🖥️ Debian
> **必须填写实测数据**：10 局的队友歼敌占比、玩家歼敌占比、队友平均存活、CPU 占用；调整了哪些参数、调整前后对比。
> 只写「已完成」不算数。

#### 💻 Mac
> 填写：队友状态面板与喊话的表现效果、三路指示器是否够醒目

- [ ] 空投调度：间歇期 + 每 45 秒，25 秒后消失
