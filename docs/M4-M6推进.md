### 7.1 当前未提供生图接口时

素材 Agent 只负责：

- 整理角色和武器缺口；
- 为每项素材生成可审核的 Image Prompt；
- 定义输出尺寸、透明背景、命名和目录；
- 检查现有素材是否可继续使用；
- 生成待补素材清单。

在 Watson 提供生图接口之前：

- 不调用任何生图 API；
- 不消耗生成额度；
- 不读取或猜测 API Key；
- 不把 T-Pose 通过拉伸、旋转冒充自然战斗姿态；
- 主开发 Agent 继续使用程序化占位素材推进。

由 Watson 在主对话中单独提供：

- API 地址；
- 鉴权方式；
- 请求示例；
- 返回格式；
- 图片尺寸和透明背景支持；
- 是否支持 seed、参考图和批量生成。

素材 Agent 只有在 Watson 明确授权当前批次后，才可以调用接口。

### 7.3 素材 Agent 的输出

角色素材至少需要：

- `idle`：自然站立、双手持枪；
- `run`：自然行进；
- `fire`：射击姿态；
- 可选 `death`：非血腥倒地或淡出。

武器素材至少需要：

- 第一人称右下角构图；
- 枪托位于右下；
- 枪身向左上延伸；
- 枪口指向准心方向；
- PNG-32、透明背景；
- 不使用完整侧视图直接平铺。

所有生成结果必须经过：

- 透明背景检查；
- 方向检查；
- 脚底 / 枪口完整性检查；
- 尺寸和宽高比检查；
- 视觉预览确认。
